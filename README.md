Clean Hub Website

Clean Hub is a modern cleaning service website designed to help customers discover professional cleaning solutions and easily request services. The website provides a clean, responsive, and user-friendly interface suitable for a cleaning agency.

Project Overview

This project was developed as a front-end website for a cleaning business. It focuses on presenting cleaning services, building customer trust, and providing a simple booking process through WhatsApp integration.

Features

- Responsive design for mobile, tablet, and desktop devices
- Modern landing page layout
- Hero section with service introduction
- Cleaning service categories
- About section
- Contact section
- Cleaning service request form
- WhatsApp booking integration
- Smooth user interactions using JavaScript
- Styled with Tailwind CSS

Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Git and GitHub
- Vercel for deployment

Project Purpose

The goal of this project was to create a professional online presence for a cleaning company where potential customers can understand available services and quickly request cleaning assistance.

Future Improvements

Planned improvements include:

- Adding a backend booking system
- Connecting a database for customer requests
- Adding customer reviews
- Improving SEO optimisation
- Adding more animations and interactive features
- Integrating online payment options
